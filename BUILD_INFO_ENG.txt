KNOWN STARTUP ISSUE – FIXED
---------------------------
A problem that could cause the game to start with a black window when
game data could not be loaded has been addressed in this build.

DataX must be a real copy of the original game's data folder.

Shortcuts, symbolic links and junctions are not supported.

If you do not want to duplicate the DataX folder, you can instead configure
an absolute path to your existing data0001.lib file in game.ini.

If the reconstruction cannot load any game data, it will now create:

  startup.log

next to cultures_reconstruction.exe.

Check this file if the game starts with a black window or fails to reach
the main menu.
