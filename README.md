# Cultures: 8th Wonder of the World - Reconstruction Test Build

🌐 **Language / Język:**  
🇬🇧 **English** | [🇵🇱 Polski](PL_README.md)

This repository contains public test builds of the **Cultures: 8th Wonder of the World Reconstruction Project**.

The project is currently under active development and is **not a finished replacement for the original game**.

The purpose of these builds is to test the reconstruction, find bugs and compare its behaviour with the original Cultures: 8th Wonder of the World.

## Download

Please download the newest version from the **Releases** section.

Do not download individual files from the repository unless you know what you are doing.

## Original game data required

Original Cultures game assets are **NOT included**.

You need your own copy of **Cultures: 8th Wonder of the World**.

After downloading the test build:

1. Find the `DataX` folder in your Cultures installation.
2. Copy the entire `DataX` folder next to `cultures_reconstruction.exe`.
3. Run `cultures_reconstruction.exe`.

Full instructions are included in:

- `README_TEST_BUILD_ENG.txt`
- `README_TEST_BUILD_PL.txt`

## Current status

This is an early test build.

Some systems are already working, while many others are still incomplete or under development.

Expect:

- missing features
- incorrect behaviour
- graphical issues
- unfinished systems
- crashes
